BeeHive encrypted backups

A personal application for saving encrypted home-server configuration backups to the owner's Google Drive. It is operated by its owner for their own use and has no public sign-up.

The server creates and encrypts an archive locally, uploads the encrypted file using rclone, downloads it to verify its checksum, and maintains a limited set of verified recovery copies. The decryption key is kept separately from Google Drive.

The application requests Google's drive.file permission, covering only specific files used with this application. It does not request access to all Google Drive files, Gmail, contacts, or calendars.

Google sign-in is used only to authorize the owner's backup connection. This website performs no sign-in and collects no form submissions.
